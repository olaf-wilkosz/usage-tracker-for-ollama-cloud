# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Use GitHub's private reporting:
[Report a vulnerability](https://github.com/olaf-wilkosz/usage-tracker-for-ollama-cloud/security/advisories/new).

Include what you found, how to reproduce it and the extension version. You will get a first answer within a few days.

## What is in scope

The extension handles one secret, the user's Ollama API key. Reports about how it is stored, transmitted, logged or exposed (to web pages, other extensions, the clipboard, diagnostics) are especially welcome. See [docs/architecture.md](docs/architecture.md#api-key-storage) for the design and its stated limits.

## Supported versions

Only the latest release receives fixes.
