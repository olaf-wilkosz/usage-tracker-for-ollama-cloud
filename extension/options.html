Configure Usage Tracker for Ollama Cloud

Ollama account Connected

The extension reads your usage through Ollama's official API, which needs an API key. It takes a minute:

  1. Open ollama.com/settings/keys and create a key (name it e.g. “Usage Tracker”).
  2. Copy the key and paste it below.

Ollama keys can't be limited to read-only, so treat this one like a password. Here it is stored encrypted, sent only to ollama.com, and never shown again. You can revoke it any time at ollama.com/settings/keys.

Refresh Interval

How often to fetch usage data from Ollama. Minimum 1 minute to avoid rate limiting.

Notification Thresholds

Show system notification when usage exceeds these percentages.

Display

Peak / off-peak hours come from the pricing page at ollama.com/pricing (weekdays 12:00–18:00 UTC are peak) and are computed locally.

Diagnostics

If the popup reports a problem with the Ollama API, copy the last responses it received (usage numbers and model names only - never your API key) to share when reporting it.

Data Management

Clear all locally stored usage data and reset the extension.
