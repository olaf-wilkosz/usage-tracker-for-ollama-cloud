Usage Tracker for Ollama Cloud

Connect your Ollama account

The tracker reads your usage through Ollama's official API and needs an API key. It takes a minute.

  1. Create an API key at ollama.com and copy it. This popup closes when you switch tabs; just reopen it from the toolbar.
  2. Paste the key here:

Ollama keys can't be limited to read-only, so treat it like a password. Here it is stored encrypted, sent only to ollama.com and never shown again.

📌 Pin it to the toolbar to keep the live badge in view: extensions menu (puzzle icon), then the pin.
