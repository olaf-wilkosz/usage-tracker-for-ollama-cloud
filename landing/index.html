Set up in a minute

The extension reads your usage with an API key from your own account.

  1. Install itAdd the extension to your browser. It opens its setup by itself on first install.
  2. Create an API keyOn ollama.com/settings/keys, create a key and copy it.
  3. Paste it inInto the popup. The extension checks the key with Ollama, stores it encrypted and starts tracking.

Private by design

No account, no servers of ours, no analytics. Your key and your usage data never leave your browser except to ask Ollama for your own numbers.

Read the privacy policy

  • The only server it contacts is ollama.com, with read-only requests and no cookies.
  • Your API key is stored encrypted on your device and is never shown again.
  • Ollama keys can't be limited to read-only, so treat yours like a password. You can revoke it any time at ollama.com/settings/keys.
  • Only three permissions: storage, alarms and notifications. One host: ollama.com/api.
  • MIT licensed. Read every line.

Questions

Is this an official Ollama product?

No. It is an independent, unofficial project and is not affiliated with or endorsed by Ollama. It uses Ollama's public, documented API.

Which plans does it support?

All of them, following the official API documentation: pay as you go (credits balance, spend and a low-credits alert), plans with included monthly credits (Pro, Max, Team) and the older session and weekly windows. It was developed against a pay-as-you-go account (the former Free plan); the other shapes come from the documentation and could not be tried on real accounts. If something looks off, the diagnostics button in the settings gives you a report you can attach to an issue.

Why does it need an API key?

The usage API only answers requests that carry an API key. Pages on ollama.com are not scraped, so nothing breaks when the website changes.

Can the key be read-only?

Not today: Ollama API keys have no scopes. That is why the extension keeps the key encrypted, sends it only to ollama.com and lets you remove it with one click.

Which browsers?

Chrome, Edge and Brave (version 110 or newer), and Firefox and Zen (version 140 or newer). It is the same extension code in all of them, so they behave the same.

What does it cost?

Nothing. It is free and open source under the MIT license.
