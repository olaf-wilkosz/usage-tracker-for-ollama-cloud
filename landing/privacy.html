Privacy policy

Usage Tracker for Ollama Cloud · last updated November 2026

Usage Tracker for Ollama Cloud (“the extension”) is a browser extension that shows your own Ollama Cloud usage. It is an independent project by Olaf Wilkosz and is not affiliated with Ollama. This policy says what the extension stores, what it sends and where. The short version: everything stays in your browser, and the only server the extension talks to is ollama.com.

1. What is stored on your device

All data is kept in the extension's local storage in your browser (storage.local) and nowhere else. Nothing is synced and nothing is sent to the developer.

2. What is sent, and to whom

The extension sends read-only GET requests to the official Ollama API and nowhere else:

  • https://ollama.com/api/balance
  • https://ollama.com/api/usage (24-hour and 30-day ranges)

Each request carries your API key in the Authorization header. Requests are made without cookies and without a referrer. Ollama's own terms and privacy policy apply to what Ollama does with those requests.

3. What the extension does not do

  • No analytics, telemetry, crash reporting or advertising.
  • No servers operated by the developer; there is nothing to send your data to.
  • No access to the pages you browse, your history, bookmarks or cookies.
  • No sale, sharing or transfer of data to third parties.
  • Data is used only to provide the features described above, in line with the Chrome Web Store User Data Policy including its Limited Use requirements.

4. Permissions

  • storage: keeps the encrypted key, usage data, activity history and settings on your device.
  • alarms: refreshes your usage on the interval you choose.
  • notifications: shows the usage alerts you enable, and the “Send test” notification.
  • Host access to https://ollama.com/api/*: lets the extension call the Ollama API.

5. A note about API keys

Ollama API keys cannot currently be limited to read-only access, so a key can also be used to run models on your account. Treat it like a password. The extension keeps it encrypted and sends it only to ollama.com. You can revoke it at any time at ollama.com/settings/keys.

6. Deleting your data

  • Remove key from this browser (extension options) deletes the key and the usage data read with it (settings and activity history are kept).
  • Clear All Local Data (extension settings) deletes everything the extension stores, including settings and history.
  • Uninstalling the extension removes all of its data from your browser.

7. Changes and contact

If this policy changes, the date above is updated and the change is described in the project's release notes. Questions about privacy: open an issue at github.com/olaf-wilkosz/usage-tracker-for-ollama-cloud/issues. The source code is public at github.com/olaf-wilkosz/usage-tracker-for-ollama-cloud, so every statement above can be checked.
