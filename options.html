Options

Configure Ollama Cloud Usage Tracker

Refresh Interval

How often to fetch usage data from Ollama. Minimum 1 minute to avoid rate limiting.

Notification Thresholds

Show system notification when usage exceeds these percentages.

Display

Peak / off-peak hours come from the pricing page at ollama.com/pricing (weekdays 12:00–18:00 UTC are peak) and are computed locally.

Diagnostics

If the popup says it cannot read the Ollama page, copy a sanitised snapshot of the page (e-mail addresses masked, no cookies) to share when reporting the problem.

Data Management

Clear all locally stored usage data and reset the extension.

About

Ollama Cloud Usage Tracker v1.1.0
Privacy-first: No telemetry, no external servers, all data stays in your browser.
